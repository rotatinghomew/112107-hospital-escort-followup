# 陪诊与后续康复衔接资料

用于梳理陪诊申请、预约变动、人员承接、执行反馈和后续支持。资料为虚构演练记录，结果状态并非健康结论。

## 数据

`data/` 中的 CSV 是本地合成资料，按 UTF-8 编码。`data-contract.json` 记录各来源文件的字段及行数。日期采用 ISO 8601 写法；空字段表示来源没有提供该值，不代表业务上的零值或已确认否定。

## 环境与检查

项目使用 Python 3.14 标准库，不需要额外安装包。在项目目录运行 `python3 -m unittest discover -s tests -v`，可检查合成资料的文件、字段和基本格式。运行 `python3 -m compileall -q tests` 可核对测试文件语法。

当前基线只定义输入资料及其格式，不提供上述业务资料的分析、决策或状态处理能力。
